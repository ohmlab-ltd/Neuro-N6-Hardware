## Archived documents

The [Neuro N6 Rev B schematic](neuro-n6/archive/Neuro-N6-Schematic-Rev-B.pdf) is retained for owners of earlier boards. It does **not** describe the current Rev C production hardware.

## Before using a schematic

Check the revision marking on the physical PCB. A schematic for another revision may contain different components, pin assignments, or power circuitry.
