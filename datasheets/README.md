# Datasheets

This directory contains the current OhmLab hardware datasheets, grouped by product. Each datasheet states the hardware revision it describes.

| Product | Current hardware | Datasheet | File |
|:--|:--:|:--:|:--|
| Neuro N6 | Rev C | Rev E | [PDF](neuro-n6/Neuro-N6-Datasheet-Rev-E.pdf) |
| Neuro Vision OV5640 and OV5640-W | Rev B | Rev D | [PDF](neuro-vision-ov5640/Neuro-Vision-OV5640-W-Datasheet-Rev-D.pdf) |
| Neuro Vision ST Cam | Rev B | Rev D | [PDF](neuro-vision-st-cam/Neuro-Vision-ST-Cam-Datasheet-Rev-D.pdf) |
| Neuro Vision Thermal | Rev C | Rev D | [PDF](neuro-vision-thermal/Neuro-Vision-Thermal-Datasheet-Rev-D.pdf) |
| Neuro Vision TFT and TFT-W | TFT Rev A, TFT-W Rev B | Rev D | [PDF](neuro-vision-tft/Neuro-Vision-TFT-W-Datasheet-Rev-D.pdf) |
| Neuro N6 Debug Adapter | To be announced | Not yet published | Not available |
| B-CAMS-IMX Adapter | To be announced | Not yet published | Not available |

The datasheet revision is tracked separately from the hardware revision. Schematics are in the [schematics index](../schematics/README.md).
